# create-jot

Crie um app web para TypeScript com JOT. O comando delega para o mesmo generator de projetos usado por `@jot/cli`.

```sh
npm create jot@latest blog
cd blog
npm run migrate
npm run dev
```

Passe `--no-install` para gerar os arquivos sem instalar dependências, ou omita o nome do app para informar o nome pelo prompt. Requer Node.js 24 ou superior.

Consulte o [guia do framework](https://github.com/Bruno-BRG/js_on_tracks/blob/master/README.pt-BR.md) e o [app de exemplo gerado](https://github.com/Bruno-BRG/js_on_tracks/tree/master/examples/blog).
