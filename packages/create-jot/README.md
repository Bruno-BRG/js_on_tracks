# create-jot

Create a new JOT TypeScript web application. The command delegates to the same project generator as `@js_on_tracks/cli`.

```sh
npm create jot@latest blog
cd blog
npm run migrate
npm run dev
```

Pass `--no-install` to create the files without installing dependencies, or omit the app name to be prompted interactively. Requires Node.js 24 or newer.

See the [framework guide](https://github.com/Bruno-BRG/js_on_tracks#readme) and [generated app example](https://github.com/Bruno-BRG/js_on_tracks/tree/master/examples/blog).
